# Product Requirements

## Product

RoleAxis Evidence is a premium evidence operations platform for immigration, academic, and professional portfolio cases.

## Supported Case Types

- NIW
- EB-1A
- O-1
- Academic Promotion
- Professional Portfolio

## Core Workflows

1. Register a business account.
2. Log in and maintain a secure session.
3. Create a case workspace.
4. Upload evidence documents.
5. Import candidates from the document organizer.
6. Import safe candidate summaries from the email crawler.
7. Categorize evidence.
8. Generate exhibit numbers and professional filenames.
9. Generate readiness insights.
10. Export an attorney-ready ZIP package.
